# Animal-Shelter-Analytics

반갑습니다 여러분~~
- 데이터셋은 전처리 과정을 거친 동일한 데이터셋을 사용해야 모델 비교할 떄 의미가 있습니다
- 따라서 7월 18일(토) 내로 최종 데이터셋을 올려둘거고 여러분들도 수정 가능합니다
- 다만 모델을 만들기 시작하여 각자의 모델에 학습시킨 뒤에는 데이터셋에서의 수정은 없어야합니다
- 제가 올려둔 전처리 코드에서 수정 원하는 부분 있으면 편하게 말씀주시면 됩니다

모델생성
1. 전건우 : Logistic Regression
2. 이시현 : Random Forest
3. 성소연 : LightGBM

- Github desktop 있으시면 사용하시고 없으시다면 설치 부탁드립니다
- 각자 본인 컴퓨터에서 branch 생성해서 본인 코드 저장하셔야 합니다
- main branch는 나중에 코드 합칠때 사용해야 하므로 건들지 않아주셨음 좋겠습니다

### 만약 Github desktop 사용방법을 모르신다면?
- 각자 권한 부여받은 뒤에는 gitgub desktop 위에 '파일' 클릭 후 'clone repository' 클릭하셔서 해당 저장소 갖고 오세요
- Current Repository를 Animal shelter analytics로 하시고
- 위쪽에 있는 current branch 클릭 후 본인 branch 생성하고 publish branch 까지 누르시면 됩니다
    - ex) Model-RandomForest, Model-LightGBM
