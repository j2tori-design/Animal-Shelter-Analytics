# Animal-Shelter-Analytics

반갑습니다 여러분~~
- 데이터셋은 전처리 과정을 거친 동일한 데이터셋을 사용해야 모델 비교할 떄 의미가 있습니다
- 따라서 최종 데이터셋을 올려둘거고 여러분들도 수정 가능합니다
- 다만 모델을 만들기 시작하면 웬만하면 데이터셋에서의 수정은 없는게 좋습니다

모델생성
1. 전건우 : Logistic Regression
2. 이시현 : Random Forest
3. 성소연 : LightGBM
